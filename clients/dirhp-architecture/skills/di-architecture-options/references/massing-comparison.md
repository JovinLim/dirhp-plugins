# Example: compare two massing options

Request: “Compare the compact block and the stepped block against this brief. Do not change them.”

1. Locate the two options and identify the exact saved snapshots or live stages to compare.
2. Read the brief's supplied criteria. For example, a maximum height, a site setback, and a target
   floor area. Do not supply missing numeric targets from convention.
3. Check that both use the same site reference and datum. Find the relevant massing geometry and
   declared representations. Keep source components and repeated occurrences distinct.
4. Evaluate height and boundary distance with the agreed operands and frame. If only outer masses
   exist, report floor area as unresolved; bounding boxes do not establish floor plates.
5. Read a bounded change summary and inspect the differences that explain the measured trade-offs.
   Use consistent visual views for form. Do not infer daylight performance from a screenshot.
6. Present the result with method and fidelity. Explain which criteria each option meets, where
   evidence is absent, and what further model content would resolve it. Leave the model unchanged.

If the request instead authorizes a new alternative, fork the chosen baseline before authoring.
Keep the criterion basis fixed while testing the strategy. Review staging, then save only within
the authorized task. This variation uses the same reasoning without making every comparison a
modelling workflow.
